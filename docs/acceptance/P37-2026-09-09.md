# P37 验收纪要：会话内实时输出速率（2026-09-09）

> 分支：`zhubaoduo/feat/p37_token_rate`（worktree `p37_token_rate`）
> 规格：`docs/plan-p37-token-rate.md`

## 1. 需求

每个会话实时显示当前输出速率（用户原话「每分钟输出多少 token」）。位置：聊天气泡末条下方**总时钟（TurnElapsed）右侧**。

## 2. 关键裁决（详见规格书 §0）

- **口径 tok/s，非 TPM**：社区（crush #3167 / assistant-ui / pi-token-speed / Open WebUI）无一用 TPM，数字可读性差。
- **速率是估算值**：ACP 协议无逐 token 计量流——`usage_update.used` 是上下文占用（claude-acp 每条 assistant 消息完成才发，分钟级粒度；codex-acp `thread/tokenUsage/updated` 也是秒级批量）；`PromptResponse.usage.outputTokens`（UNSTABLE）是 turn 终态。采纳社区通行形状：**流中字符估算 + 终值回算兜底**。
- **测到达侧不测揭示侧**：P35 pacer 揭示是 30fps 匀速假象，测它得到的是 pacing 参数。速率器与 `pacer.onChunk` 同点位喂入（ChatPanel 事件循环 agent_text 分支）。

## 3. 实现

| 组件 | 职责 |
|---|---|
| `streamRate.ts`（R1） | 滑动窗口（10s）字符速率 ÷ charsPerToken（CJK 占比 1.5~4 线性插值）+ EMA 0.35 平滑；窗口 <20 字符返回 null（防 0 tok/s 跳动）；样本上限 200（长流内存有界）；`finalize(outputTokens, endedAt)` 有权威终值走精确均值、无则冻结最后估算；收口后 onChunk 不污染冻结值 |
| `streamRateStore.ts`（R2） | 模块级 `Map<tabKey, {current: StreamRate}>` 登记表——速率**不进 zustand store**（P32 R2 教训：每秒变的值进 sessionSignals 编码投影会击穿 App 级浅比较全树重渲染）；ChatPanel 卸载摘除登记 |
| MessageLine 接线（R3） | `TurnElapsed` 总时钟右侧 `StreamRateBadge`（`⚡ N tok/s`）；局部 1s interval 重读 display()（与 useElapsedTicker 同频）；分档着色 <15 danger / 15-30 warning / ≥30 success（pi-token-speed 阈值）；纯 tool turn rate=null 不渲染；turn 结束冻结常驻（与总耗时常驻语义对齐）；rateRef prop 只传末条（memo 纪律同 lastEventAt） |
| session-core（R4） | `turn_stop` 事件带出 `resp.usage?.outputTokens`（前向兼容——当前 claude-acp/codex-acp 均不填，协议一旦填上显示即升级精确均值） |

## 4. 测试证据

- streamRate 12 例：匀速收敛 ±20%（英文/中文/混合）、窗口滑出归 null、<20 字符 null、EMA 抑制 10 倍突发、finalize 双分支、无 chunk turn 保持 null、样本上限不失真、reset、收口后残余事件不污染。
- ChatPanel.p37 4 例：text turn 徽标出现且 data-live=false 冻结、纯 tool turn 无徽标（活动组卡正常渲染）、权威 outputTokens 通路、多轮重走。
- session-core.prompt 断言更新：turn_stop 增加 `outputTokens: null` 字段（T2-T5）。
- 全仓 `pnpm test` **752 用例全绿**（93 文件）；`tsc` 零错误；`pnpm build` 通过。

## 5. 边界与已知限制

- 流中数值是**估算**（±20% 级误差），用途是「感知模型快慢」；账单级精确值协议上不存在。
- 纯中文长文本估算偏差最大（CJK 占比插值端点 1.5 为经验值，可用真实会话校准 `streamRate.ts` 顶部常量）。
- 工具轮间隙（无文本输出时段）速率会自然衰减到 null 并隐藏徽标——符合「当前没有在输出」的直觉。

## 6. 调优入口

`streamRate.ts` 顶部常量：`WINDOW_MS`（窗口）、`MIN_WINDOW_CHARS`（显示门槛）、`EMA_ALPHA`（平滑度）、`CJK_CHARS_PER_TOKEN`/`LATIN_CHARS_PER_TOKEN`（换算端点）；`MessageLine.tsx StreamRateBadge`（着色阈值/格式）。
