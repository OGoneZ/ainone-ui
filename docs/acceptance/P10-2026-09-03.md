## 偏差说明

1. **原 tabs-bar 自绘标签栏废弃**：flexlayout 自带 tab strip，P10 改用其内建标签（限宽/省略号通过 CSS 覆盖达成），旧 `.tab/.tabs-bar/.tab-content` 规则与 JSX 已删除。
2. **体积**：flexlayout-react（unpacked 1.8MB）入依赖，dist JS 增约 90KB（gzip），符合「体积非硬红线」金标准。
3. **App.test 的 flexlayout Layout 被 mock**：jsdom 高度为 0 时 flexlayout 不渲染 tab content，与 react-virtual 同理；mock 保留了真实 Model/Actions/DockLocation 编排逻辑，只平铺渲染 tab 内容，测试有效性不受影响（已记入 test setup 注释）。

## 结论

P10「窗口与编辑器布局」达成：最小尺寸、Chrome 式标签、分屏（快捷键+拖拽+动画）、悬浮输入框全部落地，全量回归绿。待合入 main 后由所有者复验打 tag。
