## 验证方式与边界

- **确定性逻辑**（分组/迁移/去重/归一化）抽纯函数并用单测覆盖：`groupSessions`（4 条）、`match_workspace`（3 条）、`normalize_path`（3 条）、`resolveHistoryOpen`（4 条）。
- **GUI 交互路径**（右键菜单、dialog 选目录、新建会话弹层）无法自动化点击验证，以 `tauri dev` 冒烟（应用启动、无 panic/error）+ 类型检查 + 编译通过背书。核心数据流（选工作区 → session 写 workspace_id → 侧栏分组）由前端纯函数与 Rust 命令的各自单测闭环覆盖。

## 交付汇总

- Workspace 实体（Rust：list/upsert/remove + 按 cwd 规范化去重）
- session 索引 `workspace_id` 字段 + 读时迁移（幂等、不丢数据）
- 侧栏工作区分组列表（父级工作区 + 会话 mtime 倒序 + 未归组区）
- 工作区右键菜单：新建会话 / 重命名 / 移除（移除联动会话移入未归组）
- 新建会话弹层：选 harness + 选/新建工作区（dialog 目录选择）
- Tab 携带 cwd/workspaceId，会话在工作区目录运行（openSession 支持 cwd 覆盖）

## 结论

P5「工作区模型」达成：左侧从平铺会话列表升级为工作区分组，新建会话永远知道自己归属的工作目录，升级迁移不丢任何历史会话。打 tag `v0.5.0`。
