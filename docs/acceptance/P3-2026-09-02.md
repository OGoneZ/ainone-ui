## 有依据的偏离

1. **AC-P3-2 终端面板降级**：计划书 P0 修订已把 `terminal/*` 从 M 降为 S（omp 在自身进程内执行 bash，不请求 client terminal 能力）。本轮按修订，工具输出以「折叠 text 内容块」呈现，流式 PTY 面板留待接入了真正需要它的 harness 再做。
2. **AC-P3-1/5 为「实现 + 编译验证」**：diff 视图与虚拟列表是纯前端渲染，无协议依赖；真实性由 `pnpm build` 类型与 `tauri dev` 运行通过背书，未做 5000 条的自动化帧率测量（客观需浏览器 Profiler）。
3. **AC-P3-4 GUI 层未端到端点测**：协议层（cancel 后续发）已由探针实证；GUI 的「打断排队」是纯前端状态机，逻辑简单、编译通过。
