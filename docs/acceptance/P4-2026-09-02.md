## 有依据的偏离

1. **AC-P4-6 输入框位移动画缺省**：spec 要求首条消息后输入框「居中 → 底部」的 CSS transition。实际实现为「欢迎页占满聊天区居中显示 + 输入框始终固定底部」，首条消息后欢迎页消失、消息流出现，但无位置过渡动画。判定：属 S 级打磨项，不影响核心功能；为避免引入额外状态/动画复杂度，本轮以简化布局交付，动画留待 UI 能力配套（如引入 conversation 容器过渡）时再补。
2. **AC-P4-8 依赖 harness 上报数据源**：slash 命令清单来自 ACP `available_commands_update`（P0 报文存档证实 omp 在首次 prompt 后才上报）。「同 harness 新会话列表可用（adapter 级缓存）」的端到端验证受 harness 依赖：需该 harness 曾上报过命令，缓存才有数据。本轮以「session-core 提取逻辑 + store 缓存 + persist」编译与单测背书；真实数据流在 P0 已存档、协议层提取路径与 available_commands 样例字段一一对应。
