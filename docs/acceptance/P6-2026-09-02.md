## 验证方式与边界

- **状态推导/问候语/建议**抽纯函数并单测覆盖：`deriveStatus`（6 条）、`collectSignals`（1 条）、`welcomeGreeting`/`suggestionsFor`（2 条）。
- **动画视觉**（呼吸/脉冲/高亮边）为 CSS，无法自动化断言，以「状态驱动 className + 编译通过 + tauri dev 冒烟」背书。
- **多会话并行的状态持续显示**（AC-P6-3）依赖 F-4-4 去重保证一个 sessionId 一个活跃子进程 + F-4-8 store 外提，二者均有单测（tabs 4 条、store 6 条）与 P4 记录佐证。

## 交付汇总

- 会话状态推导纯函数（working / awaiting_input / done / idle，含优先级）
- 侧栏会话状态指示（工作呼吸动画、等输入脉冲、完成静态、空闲灰点；working/awaiting 高亮边）
- 欢迎页时间段问候（夜深了/早上好/下午好/晚上好）+ adapter 差异化建议，点击直接发送
