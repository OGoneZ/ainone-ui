## 诚实标注与偏离说明

1. **AC-P2-2 的 Pi / Codex 未完全通过**：
   - **Pi**：`pi-acp` 桥接器（0.0.33）协议层 initialize/session/prompt 往返正常，但回复是 pi 的启动 banner（`pi v0.84.4`）而非模型输出——根因是 pi 本体未配置 LLM provider（需 `pi --terminal-login` 交互登录，或手写 API key 配置），**属 harness 侧未就绪，非 GUI 代码缺陷**

   - 结论：前端「统一多 harness」的协议层对这两个 harness 已通，剩余是各自的凭据配置

2. **AC-P2-7 用探针代换**：计划制定时假设自研大量需单测的逻辑；采用官方 SDK + 生产逻辑抽到 session-core（零 Tauri 依赖）后，探针能直接复用生产代码验证，比 mock 单元测试更贴近真实（DEC-8「成熟实现优先」的延伸）

3. **AC-P2-8 降级**：按计划书 F-2-3 明确允许「降级为仅显示上下文提示行」；`session/load` 已实现恢复，历史消息体回填留待 P3 的渲染升级时一并处理
