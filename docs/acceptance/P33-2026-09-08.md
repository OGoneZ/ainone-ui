## 偏离与边界（如实登记）

1. **通知点击唤起窗口降级**：插件 2.4.0 desktop 源码核实 notify-rust 无点击 action API——「点击通知唤起」不可达，降级 = 通知提醒 + 平台原生交互（Dock/任务栏）回应用户。将来插件支持 action 时零改动升级。
2. **托盘可见性与菜单点击**待 GUI 手测：自动化只能证到「创建成功 + 命令链路通 + 退出语义等价」。手测清单：菜单栏图标可见 / 左键显示窗口 / 右键菜单三行 / 「运行中 N」随任务变化 / 「退出」pgrep 无残留。
3. **updater 实机端到端**需两个真实发布版本（AC-P33-13），按规格预登记方案延后：当前 R2 无 latest-updater.json → 应用「检查更新」走 error 态显示原因，行为合理；完整链路随下次所有者打 tag 收口。
4. **版本号 bump 不日常执行**：门禁在发版时校验 tag==conf + 严格递增（用户 tag 节奏决策 BASE-01）。下次发版步骤：bump package.json + tauri.conf.json → 配 secrets → 打 tag。
