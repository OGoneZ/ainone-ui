## 4. 实施中发现与修正（对规格书的偏差）

1. **DEC-21 修正**：`@streamdown/code` 的 Shiki 双主题（github-light/github-dark）经 CSS 变量 + `dark:` 变体生效，仓库 `@custom-variant dark` 已绑定 `data-theme`，无需额外适配 —— 规格书 §7 风险项「样式 purge」用 `@source` 指令解决（已验证 build 产物含样式）。
2. **ansi-to-react interop**：CJS 单导出（`exports.default`），Vite ESM interop 后需二次解包 default，已在 `AnsiView` 内处理（`dec02ca`）。
3. **katex 显式依赖**：@streamdown/math 的 katex 传递依赖被 pnpm 隔离，顶层 import 其 css 失败 → 显式安装（`401c4fa`）。
4. **工具 JSON 输出走代码块路径而非 ANSI**（ToolTextView 三分支）：pretty 后的 JSON 直接用等宽 pre 呈现，避免双层包装；规格书 AC-R6-2 措辞「按代码块渲染」以实现为准。
5. **首包体积**：index chunk 2.3MB（gzip 670KB）——shiki 全语言按需加载已拆 chunk，但 streamdown/mermaid 核心进主包。20MB 非硬红线，后续可用 manualChunks 优化（记入 ideas 备选，不在本期）。
