# P26 需求规格书：工具栏精简 + 侧栏底部动作区

> 背景：顶部工具栏利用效率低（一行只有少量低频按钮），侧栏头部按钮重复（两个「新建终端」），
> 主题选择占工具栏一席。本任务把低频动作归位：主题进设置，设置/打赏进侧栏底部，工具栏整行移除。

## 现状（改动前）

```
┌─────────────────────────────────────────────────────────┐
│ [＋新建会话] [⌘新建终端]      ……(空白)…… [☕打赏作者][⚙设置][主题:跟随系统▾] │ ← toolbar 整行
├──────────────┬──────────────────────────────────────────┤
│ 工作区  [⌗][＋][>_][«] │  flexlayout 窗格区                        │ ← sidebar-head（4 个图标钮，其中 2 个是"新建终端"）
│  ├ 会话分组…   │                                          │
│  └ 会话分组…   │                                          │
└──────────────┴──────────────────────────────────────────┘
```

## 需求与验收标准

### R1 移除顶部工具栏整行

**目标**：删除 `.toolbar` 整行（新建会话、新建终端、打赏作者、设置、主题全部移出），
为聊天窗格腾出垂直空间。相关入口去向见 R2/R3/R4。

**验收标准**：
- AC-R1-1：页面上不再渲染 `.toolbar` 行；聊天窗格区域顶部不再有空白栏。
- AC-R1-2：新建会话仍有入口（侧栏头部 + 号，见 R2）；新建终端仍有入口（侧栏头部终端图标，见 R2）；
  打赏作者/设置移至侧栏底部（见 R4）；主题移至设置弹窗（见 R3）。
- AC-R1-3：`App.test.tsx` 中原「toolbar 新建会话按钮」的测试引用改为侧栏头部入口后全部通过。

### R2 侧栏头部按钮去重

**目标**：侧栏头部（"工作区"标题行）只保留 3 个图标按钮：终端、会话（+）、收起侧栏。
现有两个「新建终端」按钮（`SquareTerminal` 复杂图标与 `Terminal` 简单图标各一）去重：
**删除第三个（简单 `TerminalIcon`）按钮，保留 `NewTerminalIcon`（SquareTerminal 复杂图标）**。

**验收标准**：
- AC-R2-1：侧栏头部从左到右恰为：`SquareTerminal`（新建终端）、`Plus`（新建会话）、`PanelLeftClose`（收起侧栏），
  共 3 个按钮，均 icon-only（现有样式）。
- AC-R2-2：三个按钮功能不变：新建终端（归属活跃 tab 工作区）、打开新建会话弹层、收起侧栏。
- AC-R2-3：全应用不再出现两个相邻的「新建终端」入口（侧栏头部范围内）。

### R3 主题选择移入设置弹窗

**目标**：`.toolbar` 的「主题：跟随系统/浅色/深色」下拉移入 SettingsModal，
作为「外观」分区（置于「模型服务」之前），交互与持久化行为不变（localStorage `ainone-theme`，auto 跟随系统）。

**验收标准**：
- AC-R3-1：设置弹窗出现「外观」分区，内含主题下拉（auto/light/dark 三选项，文案不变）。
- AC-R3-2：选择主题后 `localStorage["ainone-theme"]` 立即落盘，应用 `data-theme` 实时切换（沿用现有 App effect）。
- AC-R3-3：工具栏移除后主题功能无回归：auto 模式下系统明暗变化仍实时生效（现有 matchMedia effect 保留在 App）。

### R4 设置/打赏作者移入侧栏底部

**目标**：侧栏底部新增固定动作区（footer），**上：打赏作者，下：设置**，上下两行排列；
每项 = 图标 + 文字。侧栏折叠时该项只保留图标（文字隐藏），与其他折叠态按钮一致。

**验收标准**：
- AC-R4-1：侧栏底部固定显示两行动作：「打赏作者」（上）、「设置」（下），各含图标+文字，点击行为与原工具栏一致。
- AC-R4-2：footer 固定在侧栏底部（不随会话列表滚动）；会话列表滚动区域高度相应缩短
  （**原「会话分组高度上限」整体上移**，为 footer 让位），内容溢出时列表区内部滚动，footer 恒可见。
- AC-R4-3：点击「打赏作者」弹出 DonateModal；点击「设置」弹出 SettingsModal（行为与原工具栏按钮一致）。
- AC-R4-4：侧栏折叠态（`sidebar-collapsed`）footer 同步收窄为图标竖排（打赏在上、设置在下），点击行为不变。
- AC-R4-5：拖宽侧栏时 footer 与把手不冲突（把手仍贴 aside 右缘全高，footer 在 padding-box 内正常布局）。

## 不做的事（边界）

- 不改 SettingsModal 其余分区内容与保存逻辑（只新增「外观」分区）。
- 不改 DonateModal。
- 不改 flexlayout 窗格区、右栏（RightRail）。
- 不动侧栏拖宽把手（p22 系列刚修复完，只验证不被 footer 破坏）。
- 键盘快捷键（Ctrl+B/M/N/T 等 P25 四键）不受影响（走 window keydown，与 DOM 移除无关）。

## 实施顺序

S1 R2（侧栏头部去重，独立小改）→ S2 R4（侧栏 footer + 会话列表高度让位）→
S3 R3（主题进设置）→ S4 R1（删 toolbar 整行，最后删避免中间态入口断档）→ S5 全量回归 + 真机验证。

## 风险与缓解

- **测试引用断**：App.test 的「新建会话」按钮定位依赖 toolbar 文案 → S4 时同步改测试（取侧栏头部按钮）。
- **HMR 残留**：真机验证前重启 dev 或强刷新，避免旧 DOM 结构残留误判。
- **折叠态回归**：折叠态现有 2 按钮（展开/新建），加 footer 后共 4 图标竖排，确认间距样式不挤。
